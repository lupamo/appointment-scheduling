# Appointment Scheduling with M-pesa Deposits

## Product Summary
A self serve booking tool for service businessess (salon, therapists, consultants) in Kenya. Bookings are only confirmed after the customer pays a deposite via M-pesa STK push. Solving the no-show provlem that other tools cannot address.

## Target User
Solo or small service business owner (salon, spa, therapists, consultants) who currently book via whatsapp/DM and loses revenue to no shows.

## Core Valur Proposition
"Your customer can't book a slot without paying a deposit first, no more no shows."
